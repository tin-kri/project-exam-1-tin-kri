# Lenore Poe, Blog
## First year exam
A literary blog about books, writing and everyday life, built with HTML, CSS and JavaScript using WordPress as a headless CMS.


## Description

This project was made for Project Exam 1 at Noroff. The goal was to build a blog site where all content is stored in WordPress and fetched through the WordPress REST API. The blog is written by a fictional author living in London and features haikus, poems, short stories and chapters from an unfinished book. All blogs are written by AI

The site includes:

* A home page with a "Latest Posts" carousel
* An about page
* A blog page that shows 10 posts, with a button to load more
* A post page built dynamically from a query string
* A contact page with JavaScript form validation

## Built With

* HTML
* CSS
* JavaScript
* [WordPress REST API](https://developer.wordpress.org/rest-api/)
* [Netlify](https://www.netlify.com/)

## Getting Started

### Installing

1. Clone the repo:

```
git clone https://github.com/tin-kri/project-exam-1-tin-kri
```

2. No dependencies are needed. 

### Running

Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

The live site can be viewed here: [Lenore Poe](https://lambent-llama-93fe7c.netlify.app/)
